CARA IMPORT DB
1. Salin folder inventaris ke C:\xampp\htdocs\.
2. Buka XAMPP Control Panel, lalu klik Start pada Apache dan MySQL.
3. Buka http://localhost/phpmyadmin di browser.
4. Klik tab Import di menu atas.
5. Klik Choose File, lalu pilih database.sql dari folder inventaris.
6. Klik tombol Import di bagian bawah halaman.
7. Pastikan database inventaris_db muncul di panel kiri, dengan tabel kategori, supplier, produk, dan log_aktivitas.
8. Buka http://localhost/inventaris/ untuk menjalankan aplikasinya.
